# X2D II 四亿 RAW／JPEG 常驻版源码

2026-10-08 晚间常驻快照，固件限定 **1.3.16.2**。历史目录名 `pixel_shift_raw` 保留，当前支持 **RAW、RAW+JPEG、仅 JPEG**，不支持 HEIF／RAW+HEIF。第一代 X2D 的地址和安装器不能直接用于本机型。

## 当前流程

- 沿用稳定六帧采集、128 行提前处理和四亿 RAW 合成；RAW 封装未因本次 JPEG 更新而替换。
- JPEG：九块原厂显影、硬件 Q80 编码、压缩域并行拼接，提取首帧预览与拍摄元数据。保留已经验收的 JPEG 封装、4 KB 对齐及 MakerNote 信息；不添加自写显影或锐化。
- RAW+JPEG 的两个文件保存并作为同一相册条目登记；仅 JPEG 只发布 JPG，不发布配套 RAW。
- 登记、文件身份和编号提交成功后，使用原厂存储删除接口清理本次六张原片，同时更新相册索引。配对模式必须同时确认 RAW 和 JPG；仅 JPEG 必须确认 JPG。删除中断不重发不确定操作，保留尚未删除的原片及恢复记录，不删除历史测试原片。
- 保留当前辅助放大、拖动／缩放停稳后更新和防闪烁逻辑。有有效配对 JPEG 时优先读取 JPEG；不要把历史原厂 RAW 缓存实验描述成当前仅 RAW 路径已全部接入。
- 切入像素超频时提前准备驱动和 Auto6，退出时恢复；浏览菜单时不锁定 AE、不改图像格式。曝光快照和 AE 锁定仍在拍摄阶段进行。倒计时结束至请求的最近实测仍约 2.63 秒，尚未完全消除等待。

## 验证范围

- 本地 36 组清理测试覆盖三种格式、缺失成片、身份不符、同名伴随文件、删除中断及残留索引，ASan／UBSan 通过。
- 并行 JPEG 拼接在本地八组几何夹具和两轮同图实机对照中保持字节一致。实拍 RAW+JPEG 的六帧采集后处理约 58.9 秒，其中九块显影约 32.9 秒、拼接约 8 秒；这不是各曝光／存储条件下的耗时保证。
- 常驻载荷与当前会话均已安装、回读校验。用户在被要求重启并测试 RAW+JPEG 后反馈“OK没问题”；新删除分支未另行拉取该次拍摄日志，不能标作独立日志验收。仅 JPEG 自动清理已有模拟测试，仍需单独实拍验收。
- 本次只同步本地源码，不执行 Git 提交、推送或相机操作。

## 源码与构建

`release.json` 和 `resident-manifest.sha256` 记录本次已安装版本摘要；`source-manifest.json` 记录本地源码摘要。未修改的历史辅助源码仍保留，**实际构建入口以两个构建脚本为准**，不以旧实验文件名推定其正在运行。

- `src/coordinator`：当前任务串联、来源身份和三格式清理。
- `src/merge`：现有 RAW 合成器。
- `src/native-renderer`、`src/native-join`、`src/jpeg-pack`：九块显影、并行拼接、JPEG 预览和兼容封装。
- `src/capture`、`src/service`：当前 AE／Auto6 及菜单提前准备服务。服务使用独立依赖快照，不可随意替换为拍摄串联器的同名文件。
- `src/zoom`、`ui`：当前辅助放大与自写 UI 片段。
- `startup`：摘要匹配的常驻启动脚本，不是通用安装器。

离线构建核心三模块：

```powershell
python build.py --ndk <NDK-r27> --jpeg-headers <jpeg头文件目录> --camera-jpeg <固件libjpeg.so> --zoom-jpeg-config <配置头目录> --zoom-jpeg-headers <libjpeg-turbo-2.1.5.1目录> --zoom-jpeg-static <ARM64静态库> --out <输出目录>
```

构建 JPEG、采集及菜单服务模块：

```powershell
python build_native_replay.py --ndk <NDK-r27> --camera-libs <1.3.16.2的lib64目录> --out <输出目录>
```

构建脚本检查输出摘要，不连接相机。需要合法取得的 NDK、libjpeg 依赖，以及固件的 `libdbus.so`、`libduml_hal.so`、`libduml_vcodec.so`；不随源码提供。不同工具链的输出不能未经复核直接部署。

`tests/test_jpeg_cleanup.c` 是模拟 CLI 测试，不操作真实照片；使用 Linux 专用临时夹具目录，当前卷验证基于 WSL `/mnt/c`。旧测试的格式限制可能属于历史快照，不代表本版支持范围。

## 安装边界

这里是已安装版本的自写源码快照，**不是 CIM 或从零安装包**。原厂服务、安全域、存储观察器、按键模块和既有配套程序仍是前提，不能把 `startup` 直接复制到其他相机运行。未整理进独立构建入口的模块仅记录摘要，不宣称可从该目录完整重建。
