# 像素位移

[English](README.md) | [简体中文](README_CN.md)

适用于 Hasselblad X2D II 100C 的六帧四亿像素位移拍摄功能。

当前实机验证版本与固件严格绑定。源码、构建说明、验证边界和已知限制记录在对应固件目录中：

- [固件 1.3.16.2](firmware/1.3.16.2/README.md)
- [常驻启动优化 v2](firmware/1.3.16.2/startup/unified-v2/README.md)：拍摄与存储首次启动加载扩展，界面不再等待像素超频后台；已完成单次启动实机验收并安装常驻开关，常驻切换后的再次重启待验证。

此扩展包含采集、RAW/JPEG 处理、相册登记、六张原片清理和辅助回放组件。其他相机功能必须放在 `extensions/` 下的独立同级目录中。
