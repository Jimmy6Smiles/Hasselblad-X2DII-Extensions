## 修复内容

像素超频根据实际快门时长安排六帧采集和异常恢复的等待预算，修正独立就绪检查对长曝光负 Tv 值的解释。完成阶段在等待原厂拍摄服务释放确认时保持状态查询和输入门控可响应，确认完成后再提交任务收尾。原厂文件删除、元数据和相册登记流程继续保留。

此前即使只拍像素超频，多重曝光的非活动界面仍可能递归查找原厂场景对象，使后台已经完成后，后屏继续停在“正在清理原片”。本版在预览查找前先检查模式和取景状态；焦点查找仅在多重曝光选中或其焦点持有／恢复生命周期仍在进行时执行。多重曝光活动时的目标查找和焦点恢复保持原逻辑。

本次界面修复保留已验收的图像处理、色彩、镜头校正、封装与滤镜配方字节，不增加锐化、红晕或其他图像效果。像素超频不支持 HEIF。

下载本 Release 的 Windows 完整包并完整解压，保留配套资源、MOD、回退材料及电脑事务备份；核对 `SHA256SUMS.txt`、`VERSIONS.json` 和分发来源签名。公共接口由管理器维护，不能作为独立 MOD 安装，也不能只拿 ME47 或 PS16 覆盖旧配套。

本轮自动升级面向 **已完成验收的精确正式 1.2.43 配套，且四个 MOD 均完整安装登记**：滤镜 rc3、多重曝光 rc42、像素超频 rc13、永不息屏 1.0.1。其他来源、私有测试版本、缺少 MOD 或未完成事务按各自已支持流程处理；不要强行覆盖。

1. 退出 Phocus 和其他管理器，保持相机供电及 USB 连接，回到实时取景并确认照片已经保存。
2. 用新管理器读取状态，进入本轮配套升级／恢复。
3. 按提示手动正常关机再开机；使用同一电脑和所属事务继续验收。
4. 保存电脑备份与日志。遇到未知组件、通信结果不确定或事务未完成时停止后续写入，保留现场，不重复安装。

配套回退目标为本轮升级前核对并备份的正式 **1.2.43 四 MOD 组合**。本轮没有宣称任意来源新装、任意组合卸载或全环境回退均已实测。若当前构建对功能更改／卸载仍有保护，应先按配套回退恢复来源，再用其对应管理器处理；以最终包内说明为准。

## 本轮实机证据

相机端 1.2.59 目标配套已通过写入、重启和以下实拍验收；当时使用的是私有 1.2.58→1.2.59 事务。新公开管理器的正式 1.2.43→1.2.59、恢复和回退 1.2.43 路线单独采用离线测试核对，本轮未在相机上重跑这条公开迁移路线。

同一开发相机完成 1.2.59 配套写入、人工重启、实际加载及后台验收后，拍摄了一组**仅 RAW、拍后退出模式（实际 keep=false）**。成片为 `B0004178.3FR`，六张原片已清理；当前后台就绪、无恢复状态和未完成任务，系统分区恢复只读。

- 原片删除：**2.757 秒**；从清理阶段开始到任务收尾：**2.864 秒**。
- 六帧确认完成到任务收尾：**20.813 秒**，不含前面的六帧采集。
- 用户目视“正在清理原片”约 **3 秒**后回到取景；此前个别测试曾等待约 30–90 秒。
- 主线程观察未再出现旧样本中后台完成后持续约 90 秒的高负荷遍历；这只是本次单组的支持证据，没有对后屏退出帧作精确计时。

首次观察到新任务到后台完成约 37.078 秒，包含采集等阶段，与上述采集后耗时口径不同。以上均为单机单组参考，不作跨机速度承诺。旧 CPU 对照组的 keep=true 与本次 keep=false 不同；旧 keep=false 长曝光组也曾报告界面长等待，但没有相同的主线程观察数据。

**本轮没有覆盖 keep=true、连续第二组、JPEG／RAW＋JPEG、完整长曝光回归、ME47 多重曝光实拍、任意组合安装／卸载及新版 macOS。** 离线测试、实际加载和本次 RAW 成功不能替代这些验收。本轮没有新的 Mac 包；历史 Mac 包不能管理本套 1.2.59。
