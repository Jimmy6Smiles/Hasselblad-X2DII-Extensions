# 1.2.39+fm.3：Windows / macOS 配套发布

适用 X2D II 100C，原厂固件 **1.3.18.1**。本次 MOD 只有机内滤镜更新；公共运行时与安装器也有改动。小修订沿用 1.2.39，以 **+fm.3** 区分，不称为 1.2.40。

## 下载与版本

- Windows：`X2DII-Offline-Windows-Runtime-Preview-1239-fm3-Test2.zip`，含自动迁移。
- macOS Apple Silicon / arm64：`X2DII-1.2.39-macOS-arm64-Test17-Full.zip`，Test17 / build21，保留作者提供的完整包原始字节；未提供 Intel Mac 包。
- 两个完整包均包含公共运行时、45 款滤镜库和下表四个 MOD。解压后保留完整目录，Mac App 同级的 `mods` 不要移走。

|---|---|---|

## 滤镜更新

支持选择安装哪些滤镜、真实删除未选滤镜资源以释放空间、以后重新装回；增加 HDR／图像后处理提示，修复删除界面按钮闪烁，补充触屏、摇杆操作提示与长按确认。使用滤镜前请关闭 HDR／图像后处理。

实时取景快捷键是**长按 ⭕**。先选好滤镜，再进入多重曝光；进入多重曝光后不能更改滤镜。

X2D2 机内滤镜作者：[FarSails777](https://github.com/FarSails777)。管理器、公共接口、其他 MOD 及本仓库分发维护：Jimmy6Smiles；保留其他第三方和原厂组件权利。

## 安装器与公共接口

公共运行时的发行标识为 **1.2.39+fm.3**，协议版本字段仍为1.2.39；不能只看“1.2.39”就混用组件。本次保留 fm.3 精确配套资源，不重新编译四亿、多重曝光或永不息屏。

两端继承旧卸载缓存误报修复，以及安装组合变化后的上传中断续传修复；未知文件、身份不匹配或未完成事务仍会停止，不代表已解决所有断线问题。

**Windows Test2 自动升级**：原版 Windows 1.2.39 用户无需先卸载。关闭旧安装器，打开本包，读取相机状态，点击“配套升级／恢复（1.2.39+fm.3）”；需要重启时按提示正常关机再开机、回到取景，继续验收。自动处理两个同路径冲突组件，备份放电脑；保留已安装 MOD、设置及照片，不额外安装未装的 MOD。中断后恢复同一笔事务，不要重复点安装。仅接受精确核对过的原版基线，未知改版不会被强行覆盖。

**Mac Test17 的范围不同**：机内 fm.3 载荷与 Windows 相同，但此 Mac 包尚未包含 Windows Test2 新增的“原版 Windows 1.2.39 自动迁移”代码。支持包内已核对的原版1.2.35／fm.2基线及 fm.3 配套；从原版 Windows 1.2.39 迁移请先用本次 Windows Test2 完成，不要用 Mac 包强行覆盖。App 为临时签名、未公证；包内旧恢复助手仅支持固件1.3.16.2，**不可用于1.3.18.1**。

## 验证范围与使用提醒

Windows：205项离线测试通过，覆盖16种 MOD 组合、迁移中断与回复丢失恢复、原子替换与清理边界；EXE启动检查及1017项内嵌资源核对通过。**Windows自动迁移仍待实机验收，本次打包未操作相机。**

Mac：构建端报告156项离线测试、6个子测试通过，Test17版本显示、冻结资源组合和签名／解压检查通过；这是作者提供的构建记录，不是本次新增的实机验收。两个平台均不宣称适用于所有电脑。

目前尚未完全解决不同用户安装时出现的断线、失败和恢复问题。作者最近空闲时间有限，无法为每位用户单独远程排障。建议有能力借助 AI 阅读日志、核对状态和处理恢复的用户先尝试；怕麻烦、不想折腾的用户可以等待。
