# 1.2.38 配套更新（2026-10-26）

适用：Hasselblad X2D II 100C，原厂固件 **1.3.18.1**。非官方扩展，保留 rc／测试版标记。

## 本次变化

- 多重曝光 **0.1.2-rc41**：修正实时叠加取景色彩表的 BGR/RGB 通道顺序，解决无滤镜时红色变蓝、黄色变青的问题。此次只修取景显示，RAW/JPEG/HEIF 成片处理不变。
- 公共运行时 **1.2.38**：更新配套绑定，精确回退目标为 1.2.35。
- 像素超频 **1.2.5-rc11**：仅从已验收 rc8 调整版本及宿主路径绑定，图像算法和界面逻辑不变，不宣称新增提速；不含 rc9/rc10 计时诊断。
- 机内滤镜 **0.1.1-rc5**、永不息屏 **1.0.1**：包内容不变。

## 功能

多重曝光支持 2–9 张、平均／叠加／亮部／暗部、累计取景蒙版、拍摄计数、所有图像／仅限结果，以及拍后退出／保持。支持 RAW、RAW＋JPEG、RAW＋HEIF、仅 HEIF 输出；HEIF 最终成片为原厂10位链路，蒙版可使用低位深预览。仅 RAW 目前仍内部使用 R＋J 兼容采集，完成后恢复格式并清理内部 JPEG；不宣称已实现真正的 RAW 专用采集。仅 JPEG 未在本次作为可用选项发布。

零帧等待不在卡上创建任务目录；成功后的中间文件后台清理。正式照片与“所有图像”保留的原片不属于中间文件。

滤镜需先在单张选好，再进入多重曝光；模式内暂不能更换。实时取景长按 ⭕ 打开滤镜快捷入口。四亿支持 RAW／JPEG／RAW＋JPEG，**不支持 HEIF**，包含 AF-C，不另装旧独立 AF-C。

## 安装与升级

1. 下载 Windows ZIP 并完整解压。安装器内置公共接口和四个配套 MOD；无需另下全部 MOD。无同版 macOS 安装器，不要使用历史 Mac 包代替。
2. 退出 Phocus 和其他管理器，连接 USB 并回到取景。先读取状态；按安装器提示安装或使用“配套升级／恢复”。拍摄、重启均由用户手动完成。
3. **直接配套升级仅支持精确 1.2.35 配套；回退也仅返回对应 1.2.35。** 不支持 1.2.31、1.2.36、1.2.37 或任意旧版强制覆盖。其他环境先用匹配管理器完成卸载、重启验收和残留核对，再安装。
4. 出现超时或未完成事务时，保存电脑备份和日志，按提示恢复，不反复覆盖、抢占 USB 或手动删除任务标记。旧版 Release 保留。
5. 升级原厂固件前先卸载 MOD 和公共接口，检查 /data 与 /system 旧组件；刷固件不能代替卸载。不要删除照片或按名称批量清理未知目录。

安装断线及恢复问题仍可能出现，维护者无法逐台远程支持。AI 辅助不能代替状态核对。详细注意事项见仓库安装指南。

## 验证范围

本机已完成 1.2.35 → 1.2.38 配套升级、重启验收和安装收尾；用户确认 rc41 无滤镜彩色实时取景、放大退出后的蒙版恢复、两帧 RAW＋JPEG 合成、整张回放和放大拖动正常。

此前版本已验证 10位 RAW＋HEIF／仅 HEIF 输出与回放、滤镜联动、3/4张累计预览、零帧不落盘和成功后台清理；本轮未重新遍历所有格式、2–9张及四种模式。120项离线测试、620项包内资源校验不是所有设备、存储卡、全新安装、卸载或回退的实机保证。四亿本轮仅做路径适配，不宣称重新拍摄验收或解决已有相册退出等待问题。
