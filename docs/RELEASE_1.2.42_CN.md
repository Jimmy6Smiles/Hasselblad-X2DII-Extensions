# 1.2.42：四亿RC13与Windows完整配套

适用 **Hasselblad X2D II 100C / 原厂固件1.3.18.1**。

本次修复四亿在新版公共接口下进入JPEG显影阶段后退出的问题。旧程序不能识别新版界面宿主的子目录，导致显影／校准会话检查拒绝；菜单可能进一步显示“拍摄接入尚未完成”。本版同时修正四亿处理端和校准钩子的路径解析，并更新公共入口及采集宿主的完整组合准入。需要安装整套配套，不能只替换一个显影程序或MOD。

## 从正式1.2.41升级

1. 关闭Phocus和旧管理器，完整解压新Windows包；保持相机供电及有线连接，回到实时取景。
2. 用新管理器读取状态，选择“配套升级／恢复”。仅精确匹配的正式1.2.41配套及有效记录允许本轮自动迁移；保留原管理器和电脑备份。
3. 按提示手动正常关机再开机，回到取景后继续恢复／验收，直到管理器确认完成。
4. 已安装的其他MOD、设置和照片保留；未安装的功能不会因为更新自动增加。遇到超时、身份不符或未完成事务时保留日志，按所属事务继续，不要反复安装或强制覆盖。

其他旧来源继续走各自已支持的升级／恢复步骤，本轮不承诺任意旧版直接迁移。更新相机原厂固件前的完整卸载要求仍见[安装升级说明](../INSTALL_UPGRADE_CN.md)。

**不要单独把RC13覆盖到1.2.41或更旧公共接口。** 公共运行时的逻辑版本是1.2.42；原生组件仍沿用固定存储ABI，部分路径包含`common-runtime/1.2.39`。两者不是同一个版本字段，不能通过改目录名代替配套更新。

## 已知升级收尾情况

本轮实机升级曾在完整文件写入、回读之后，最后恢复系统只读时收到命令失败，管理器因此暂停，并未将升级标为完成。正常关机再开机后，使用同一电脑和原事务继续“配套升级／恢复”，已通过系统只读、实际加载和后台就绪验收。本版保留该处理流程，没有宣称修复底层挂载原因。

若遇到同样收尾失败，请保留技术日志和电脑备份，确认没有照片保存后正常重启，再读取状态、继续所属事务；不要反复安装或自行修改完成标记。其他错误仍需按具体日志处理，不能仅凭“操作未完成”判断为同一情况。
