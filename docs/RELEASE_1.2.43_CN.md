# 1.2.43：机内滤镜颜色修正版 · Windows 加固打包

适用于 **Hasselblad X2D II 100C / 原厂固件 1.3.18.1**。

本版修正机内滤镜转换时的 RGB／BGR 通道解释，使 CineStill 800T 和 Gold 200 的冷暖方向恢复正常。公共运行时为 **1.2.43**，机内滤镜为 **0.1.2-rc3**。不包含红晕、RAW 拍后处理或相关实验挂钩。

## 下载及配套

下载本 Release 的 **X2DII-Mod-Manager-1.2.43-Windows-Hardened.zip** 并完整解压。公共接口、45 款滤镜资源和四个匹配 MOD 已配套提供；公共接口由管理器维护，不作为独立 MOD 安装。

| 组件 | 版本 | 本次变化 |
|---|---|---|
| Windows 管理器／公共运行时 | 1.2.43 | 新滤镜身份、资源和完整组合准入；Windows 管理器原生编译加固 |
| 机内滤镜 45 款 | 0.1.2-rc3 | 26 款 CUBE 转换通道修正；19 款保留原配方字节 |
| 像素超频 400 MP（含 AF-C） | 1.2.5-rc13 | 保留 1.2.42 已验证载荷 |
| 多重曝光 | 0.1.2-rc42 | 保留原载荷 |
| 永不息屏 | 1.0.1 | 保留原载荷 |

修正编号为 17–26、29–34、36–45。FOTOS 1–15、经典黑白 16、原生 GR Negative 27、GR Positive 28、Portra 400 35 保留原配方字节。全部 45 项均核对来源及资源；这不是对所有胶片效果的重新校色或物理模拟。

长按 ⭕ 呼出滤镜面板、浓度控制、面板打开时隐藏原取景 UI、关闭时恢复的既有行为继续保留。多重曝光仍需进入模式前选好一组使用的滤镜；四亿与 AF-C 代码不变，四亿不支持 HEIF。

## 支持的升级与回退

此版升级面向 **已完成验收的精确 1.2.42 配套，且四个 MOD 均已正确安装登记**。通过“滤镜通道修正／恢复”进入配套升级，不先卸载旧滤镜。其他旧版本、缺少 MOD、未知组件和未完成事务不能强制覆盖；先使用对应版本管理器完成其原有流程。

退出 Phocus 和其他管理器，保持 USB Phocus 连接及实时取景，读取状态后按提示操作。正常手动重启，再继续同一电脑上的所属事务完成验收；管理器不会自动拍照或重启。保存电脑备份与日志，通信失败时不重复安装。

新旧滤镜库分开保存，升级前的控制文件、旧组件和公共接口回退材料保留。配套回退目标为 **1.2.42＋滤镜 rc2**，回退同时撤销本次颜色修正；保留完整解压目录及 `rollback-mods`。

本代保留安装／卸载保护：若需安装、卸载、启用或停用 MOD、卸载公共接口或清理其组件，**先使用配套回退恢复 1.2.42，再用对应 1.2.42 管理器完成**。本版不开放未完成实测的 1.2.43 任意组合安装或通用卸载，不是所有旧环境的救援工具。

已处于精确 1.2.43／rc3 稳定组合者不需要重复安装。早期红晕实验版本不在本发布包自动降级的支持范围内。

## 打包加固与验证范围

Windows 管理器采用 Nuitka 原生编译，不随公开包分发安装器 Python 源码或可直接提取的安装器 PYZ／pyc。排除生成的头文件、对象文件、测试、缓存、设备日志和私有备份。用于相机实际运行的原生组件、QML、脚本和 LUT 保留已验证字节；这部分仍属于可提取的运行资源，不宣称加密或绝对无法逆向。

原生编译仅改变电脑端分发形式，不对已验收的相机组件重新加壳或 strip。所有必要历史恢复资源、新旧滤镜库及 MOD 包均做哈希比对。以发布附件 `PACKAGING_VERIFICATION.json`、`VERSIONS.json` 和 `SHA256SUMS.txt` 为准。

开发相机已完成 1.2.43／rc3 配套写入、手动重启、45 款库及四个 MOD 配套身份验收；用户确认 CineStill 800T、Gold 200 实时取景正常，固定白平衡／曝光的 JPG 对照确认通道修正生效。撤销红晕实验并恢复该稳定组合后，再次通过实际加载和系统只读验收。

本轮没有重新遍历全部 45 款、HEIF 实拍、多重曝光／四亿拍摄、任意组合新装或 1.2.43 卸载。此次加固分发经过离线自检与启动检查；未因此重做相机安装或拍摄，也不将这些离线检查称为全环境实机验收。**本版没有新的 macOS 二进制包**；旧 Mac Test17 不能管理本套 1.2.43。
