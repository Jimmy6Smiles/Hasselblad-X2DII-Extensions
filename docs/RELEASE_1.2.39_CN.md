# 1.2.39 配套修正版（2026-10-26）

适用 Hasselblad X2D II 100C / 原厂固件 **1.3.18.1**。这是正式可见的 Release，功能仍保留 rc／测试版标记。

## 修正与版本

- **公共运行时 1.2.39**：修正采集宿主仍引用 1.2.35 传感器配置目录的问题，改为绑定自身版本目录。1.2.38 配套已撤回，不再推荐下载或回退。
- **像素超频 1.2.5-rc12**：沿用已验收 rc8 的功能，仅调整宿主路径与版本绑定。不含 rc9/rc10 计时诊断，不新增图像算法或提速改动。
- **多重曝光 0.1.2-rc42**：保留 rc41 的实时取景 LUT 红蓝通道修正，仅适配 1.2.39 路径；成片处理不变。
- **机内滤镜 0.1.1-rc5、永不息屏 1.0.1**：包内容保持不变。
- Windows 管理器默认采用本次成功使用的反向网络上传方式；移除回退到已撤回 1.2.38 的入口。公共运行时由安装器管理，MOD 不单独修改公共启动配置。

## 安装与恢复

完整解压 Windows ZIP，内含公共运行时和四个配套 MOD，无需重复下载。**暂无同版 macOS 二进制包**，不要用旧 Mac 包替代。退出 Phocus 和其他管理器，保持 USB Phocus 模式和实时取景，先读取状态再按提示操作。不会自动拍照或重启。

**直接配套升级仅接受安装器识别的精确 1.2.38 配套及正常登记、启动清单。** 如果此前为恢复取景重命名了 plans、恢复过原厂启动配置，或存在未知／未完成事务，不要强行覆盖；此类救援状态需要先核对，公开安装器不提供通用的一键修复。1.2.35 及其他旧环境须使用匹配管理器完成卸载、重启验收与残留检查，再安装。

本版不提供回退到 1.2.38。保留电脑备份和日志，异常时按提示恢复，不反复安装。旧 1.2.38 配套下载已撤下，其他历史版本仍仅供各自原环境使用。

**升级原厂固件前，先卸载全部 MOD 和公共接口，重启验收，并核对 /data 与 /system 的旧组件、启动项、登记及未完成事务。刷固件不能代替卸载。** 照片和未知目录不能当作残留批量删除。

安装断线、失败和恢复问题尚未在所有电脑上解决。作者最近空闲时间有限，无法为每位用户单独远程排障。建议有能力借助 AI 阅读日志、核对状态的用户先尝试，怕麻烦的可以等待；AI 不能代替校验。

## 验证边界

本机已完成新配套写入、重启加载、两个后台就绪验收和旧组件归档清理，系统恢复只读；用户确认目前正常。发布包内机身组件与这次验收的组件一致。安装器发布界面的默认传输和禁用旧版回退另经离线测试。

120 项配套测试、2 项发布策略测试及 3 项传感器配置路径回归测试通过；EXE 启动自检与嵌入资源逐项核对通过。本轮未重新遍历全部拍摄模式、格式、全新安装及卸载场景，也不保证所有用户环境无故障。

## 功能

多重曝光支持 2–9 张、平均／叠加／亮部／暗部、累计取景蒙版、拍摄计数、所有图像／仅限结果，以及拍后退出／保持。支持 RAW、RAW＋JPEG、RAW＋HEIF、仅 HEIF 输出；HEIF 最终成片为原厂10位链路，蒙版可使用低位深预览。仅 RAW 目前仍内部使用 R＋J 兼容采集，完成后恢复格式并清理内部 JPEG；不宣称已实现真正的 RAW 专用采集。仅 JPEG 未在本次作为可用选项发布。

零帧等待不在卡上创建任务目录；成功后的中间文件后台清理。正式照片与“所有图像”保留的原片不属于中间文件。

滤镜需先在单张选好，再进入多重曝光；模式内暂不能更换。实时取景长按 ⭕ 打开滤镜快捷入口。四亿支持 RAW／JPEG／RAW＋JPEG，**不支持 HEIF**，包含 AF-C，不另装旧独立 AF-C。
